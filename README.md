# MWM Wayfarer

Working title. A non-violent open-world game for Android: explore, gather, build, trade and travel between regions that each look different. Engine: Godot.

- `docs/BRIEF.md`: the owner brief. `docs/GDD.md`: game design. `docs/mockups/`: look-dev renders.
- `tools/art/`: Blender scripts that render the look-dev scenes (`scene_fjord.py` and others).
- `tools/terrain/dem_to_game.py`: turns real elevation data into the fjord scene's terrain.
